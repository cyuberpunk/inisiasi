# Internationalization

> Terakhir diverifikasi: 2026-11-16

Scope: library i18n per stack dan aturan format.

## Default

| Stack | Pakai |
|-------|-------|
| Next.js App Router | next-intl |
| Vite / TanStack / Svelte / Solid | Paraglide JS (typed, tree-shakable) |
| Nuxt | @nuxtjs/i18n |
| Vue | vue-i18n |
| Expo | i18next + expo-localization |
| Inline string gaya fbt | fbtee |
| Go | nicksnyder/go-i18n |
| Python | Babel / gettext |

## Aturan

- Semua string user masuk katalog. Jangan concat string, pakai ICU plural.
- Format tanggal, angka, mata uang lewat `Intl.*`.
- Deteksi locale: preferensi tersimpan, lalu bahasa perangkat, lalu fallback.
- Web publik multibahasa: path `/en/...`, `hreflang`, canonical.
- RTL: pakai logical properties.
- CI cek key yang hilang. Tes dengan teks panjang (pseudolocalization).
- TMS jika ada penerjemah: Tolgee (open source), Crowdin, Lokalise, Weblate.
