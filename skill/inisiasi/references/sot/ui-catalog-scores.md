# Skor katalog UI

> Dibuat 2026-11-17 dari 115 entri katalog. Jangan edit tangan: jalankan `mcp/curation/score-ui-catalog.mjs`.

Skor = bobot bundle (0-3) + netral framework (0-2) + bukti pemakaian dari katalog (0-3) + biaya adopsi (0-2).
Band: 8+ inti, 7-7.9 pilih kalau, 5.5-6.9 kondisional, di bawah 5.5 hindari.
Skor menilai kelayakan jadi default proyek baru, bukan kualitas library.
